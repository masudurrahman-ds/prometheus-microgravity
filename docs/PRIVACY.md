# Privacy

PROMETHEUS follows data minimization.

## Current local processing

Conversation memory is stored locally on the device. User-selected research files are processed only after the user chooses them.

## No unnecessary collection

PROMETHEUS does not require contacts, SMS, call logs, location, microphone, or camera access for its core research workflow.

## Future cloud AI

If a cloud LLM is enabled, the application must clearly disclose that prompts and any explicitly selected material may be transmitted to the configured service. This requires separate, affirmative user acknowledgement.

## User controls

The privacy center should expose:

- local conversation memory;
- imported documents;
- cloud-AI status;
- optional update checks;
- analytics/crash-reporting status;
- deletion controls.

Privacy documentation must be updated whenever data flows change.
