# PROMETHEUS Architecture

PROMETHEUS is designed as research software for evidence-grounded exploration of microgravity combustion and spacecraft fire-safety knowledge.

## System layers

1. **Source layer** — NASA Physical Sciences Informatics (PSI), NASA Technical Reports Server (NTRS), and other explicitly catalogued primary sources.
2. **Ingestion layer** — source acquisition, normalization, provenance capture, schema validation, and versioned manifests.
3. **Evidence layer** — structured experiments, observations, documents, media, investigation metadata, and a provenance graph.
4. **Scientific analysis layer** — unit normalization, comparison, statistics, clustering, anomaly detection, uncertainty, and hypothesis generation.
5. **Agent layer** — an LLM scientific agent that plans work and invokes deterministic tools rather than inventing measurements.
6. **Validation layer** — claim/evidence matching, causal-inference gates, uncertainty checks, citation validation, and abstention.
7. **Application layer** — Android, iOS, and web interfaces.
8. **Trust layer** — consent, permissions, privacy controls, local-data controls, security documentation, and auditability.

## Core rule

The LLM is an orchestrator and reasoning interface. NASA measurements are never generated by the model. Every scientific claim must be classified as NASA-observed, NASA-reported, derived, model-inferred, analogical, or unknown.

## Deployment

The mobile application can operate with the local evidence engine. Cloud LLM capability, when enabled, must use a secure backend; provider secrets must never be embedded in the APK or iOS bundle.
