# User Agreement and Research Disclaimer

PROMETHEUS is research software developed by The Crown Council.

Before first use, users should be shown clear information about:

1. what the application processes;
2. what stays on-device;
3. what optional services can transmit data;
4. what permissions are requested and why;
5. how local data can be deleted;
6. the difference between NASA evidence and PROMETHEUS-generated analysis;
7. the limitations of AI-generated scientific interpretation.

Consent must be affirmative and granular where optional processing is involved. A generic “agree to everything” checkbox should not be used for optional cloud processing.

PROMETHEUS is not a NASA product and must not imply NASA endorsement.
