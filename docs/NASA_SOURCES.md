# NASA Sources

PROMETHEUS prioritizes primary NASA sources.

## Primary source families

- NASA Physical Sciences Informatics (PSI)
- NASA Technical Reports Server (NTRS)
- NASA official science/program pages
- NASA-published investigation documentation
- NASA-hosted imagery/data where permitted

## Combustion investigations currently catalogued

PROMETHEUS currently maps the Flame in Freefall topic to investigations including:

ACME BRE, ACME CLD Flame, ACME E-FIELD Flames, ACME S-Flames, BASS, BASS-II, CFI, DAFT, DAFT-2, FLEX, FLEX-2, Quantitative Studies of Cool Flame Transitions, SAFFIRE-I, SAFFIRE-II, SAFFIRE-III, SAME, SAME-R, SLICE, SPICE, and utilization of SAME data for microgravity smoke modeling.

The application must distinguish a catalogued investigation from an ingested measurement dataset. Listing an investigation does not mean all of its raw data have been downloaded or reconstructed.

## Citation requirement

Use the persistent identifier/DOI supplied by the NASA source whenever available. Preserve the original source title and investigation ID.
