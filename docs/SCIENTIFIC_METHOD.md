# Scientific Method

PROMETHEUS follows a reproducible evidence-to-conclusion workflow.

1. Define the scientific question.
2. Resolve entities and variables.
3. Retrieve primary evidence.
4. Normalize units without changing source values.
5. Determine comparability and missingness.
6. Run only statistically justified analyses.
7. Separate observations, calculations, and interpretations.
8. Generate candidate conclusions.
9. Run claim/evidence and causal-inference checks.
10. Attach provenance and citations.
11. Report uncertainty and limitations.
12. Preserve the analysis trail for reproducibility.
