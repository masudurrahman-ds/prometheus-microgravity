# Evidence Policy

PROMETHEUS uses six evidence states.

| State | Meaning |
|---|---|
| NASA OBSERVED | Directly represented measurement/observation in a NASA source |
| NASA REPORTED | Statement or metadata explicitly reported by NASA |
| DERIVED | Reproducible calculation from sourced values |
| MODEL-INFERRED | Interpretation generated by the analytical/model layer |
| ANALOGICAL | Reasoning transferred from related evidence, clearly labelled |
| UNKNOWN | Not supported or not reported |

## Non-negotiable rule

A derived, inferred, analogical, or synthetic value must never be presented as a NASA observation.

## Causal language

Correlation, association, and descriptive differences do not automatically establish causation. The system must state the experimental limitations before making a causal claim.

## Synthetic data

Synthetic/demo records must be visually and textually labelled as synthetic and must never be mixed into NASA-observed evidence without an explicit evidence-state boundary.
